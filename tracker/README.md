## Scheduling policy

- Contact follow-up: 5 calendar days after a recorded last-contact date; review the thread and recipient circumstances before drafting.
- Application follow-up: 14 calendar days after the recorded applied date while the application remains Applied.
- Upcoming window: 7 calendar days after this snapshot date.
- Unknown dates stay unknown. Reminders do not create sent, submitted, or completed events.

For maintainers: edit [tracker.json](tracker.json), then run `python3 scripts/render_tracker.py --as-of YYYY-MM-DD` from the repository root.
