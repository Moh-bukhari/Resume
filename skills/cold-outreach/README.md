# Cold outreach skills

Three distilled skills for writing outreach messages that are memorable,
unique, and personalized. Each is an original distillation of a public
source (linked in the skill file), adapted for a job seeker writing to
hiring teams rather than a seller writing to buyers. Read the skill
before drafting; run the repo humanizer skill
(`../blader/humanizer/SKILL.md`) as the final pass on every message.

| Skill | Use when | Source |
| --- | --- | --- |
| [first-touch](first-touch/SKILL.md) | Writing or reviewing a first message: subject, opener, one proof point, one low-friction ask, altitude by seniority | lemlist copywriting-first-touch doctrine, https://github.com/l3mpire/claude-skills (MIT) |
| [signal-personalization](signal-personalization/SKILL.md) | Grading personalization, picking the signal, sequencing touches so each adds a new angle | forma-norden cold-email-copy-playbook, https://github.com/forma-norden/cold-email-copy-playbook (license not stated on public mirror) |
| [pattern-interrupt](pattern-interrupt/SKILL.md) | Making a draft memorable: one verifiable fact, a point of view, restraint | Moatt linkedin-voicenote-pre-warm, https://github.com/Moatt/moatt-skills (license not stated) |

## The combined method in one paragraph

Lead with one real, recent, verifiable signal from the person's own
words or work; draw the consequence for their seat; attach exactly one
proof point that matches; end with one small ask. No compliments, no
self-introduction first, no meeting ask on first contact, no second
proof point, no mail-merge personalization. If a message could go to
anyone else at the company by changing the name, it is not ready.

## Evaluated but not added

- **alirezarezvani/claude-skills (cold-email)** — large, popular bundle
  (~28K stars). Solid but generic and sales-oriented; the three skills
  above cover its ground with sharper job-seeker adaptation.
- **ognjengt/founder-skills (outreach-specialist)** — template-heavy
  (8 proven templates). Rejected on purpose: templates are what this
