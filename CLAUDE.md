# Resume repository

Read [AGENTS.md](AGENTS.md) before working here. It contains source priority,
preferences, factual constraints, navigation, skills, workflow, and checks.

historical. Start new versions from `templates/resume-base.tex`. For contact
research and letters, use `skills/README.md` and
`skills/application-workflow/SKILL.md`.
