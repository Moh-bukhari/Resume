# Letter templates

Choose the type needed now using [the letter guide](../../docs/LETTERS.md).
These are draft starting points. Replace placeholders, choose role-relevant
bank evidence, update claim/source IDs, and keep research notes outside the
copyable letter. Unused post-application or interview templates are not proof
that those events happened.

- [Before applying](pre-application-email.md)
- [After applying](post-application-email.md)
- [LinkedIn note/message](linkedin-message.md)
- [Referral request](referral-request.md)
- [Follow-up](follow-up-email.md)
- [Interview thank-you](interview-thank-you.md)
- [Formal cover letter](cover-letter.md)
- [Scheduling, offers, decisions, and references](event-response.md)

For a new role, `scripts/new_application.py` creates a folder with these drafts,
resume, contact record, and notes. The helper scaffolds files; the AI still
researches, tailors, and reviews them. Actual event states come from the user
or confirmed results, not file creation.
