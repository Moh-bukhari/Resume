# Resume starting points

- [resume-base.tex](resume-base.tex): current standalone general base using
  selected, supported bank facts; copy and tailor for each role.
- [resume-base.pdf](resume-base.pdf): one-page A4 preview of that source,
  compiled locally with pdfLaTeX and visually reviewed when this toolkit was
  prepared. Rebuild after changes; it does not validate a future revision.
- [application-notes.md](application-notes.md): copy into each application's
  `tailoring-notes.md` to record the JD, selected IDs, gaps, and real checks.

The template does not contain every experience. The full bank preserves older
engineering roles, Embersafe, Rasma, coursework, and other alternatives. Use
[the tailoring guide](../docs/TAILORING.md) to change emphasis. Tamara stays
first unless the user changes that preference.

Source comments identify selected bullet IDs. The bank is authoritative if a
later fact correction makes the template or preview stale. Root resume files
are preserved earlier variants, not the current starting point.
